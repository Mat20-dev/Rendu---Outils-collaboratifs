# Rendu - Outils collaboratifs (Chapitres 1 à 4)

Ce dépôt contient le compte-rendu des exercices des chapitres 1 à 4 du cours Outils collaboratifs.

## Contenu

Compte-rendu des exercices au format PDF.

- **Exercice_1.1** : fichiers du chatbot et déposés sur GitHub.

- **Exercice_1.2** : fichiers et dossiers de configuration du serveur Minecraft.

- **Exercice_2.2** : fichiers Python des API utilisés pour la représentation graphique des données par exemple.

- **Exercice_2.3** : fichiers Python, fichiers JSON, fichiers PyScript et les images des captures d'écran.

- **Exercice_3.1** : fichiers de l'API développée en Python.

- **Exercice_3.2** : fichier Python pour la détection des yeux sur une image.

- **Exercice_4.2** : fichier Python de l'application développée avec Streamlit.

- **Exercice_4.3** : fichier Python de la seconde application développée avec Streamlit.
